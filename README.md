# 💙 Corações Azuis

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

Experiência interativa com **HTML, CSS, JavaScript e Canvas**, com corações animados e efeitos de partículas.

## ✨ Funcionalidades
- Clique ou toque na tela para criar uma explosão de corações.
- Botão para espalhar corações com suporte ao teclado.
- Pausar e retomar a animação.
- Limpar explosões sem remover os corações flutuantes.
- Layout adaptável e respeito à preferência por movimento reduzido.

## ▶️ Executar
Abra o arquivo `index.html` no navegador. Não é necessário instalar dependências.

## 🧠 Conceitos praticados
Manipulação de eventos, desenho com Canvas, curvas de Bézier, `requestAnimationFrame`, organização de partículas e controle de desempenho.

## 📁 Estrutura
```text
index.html
style.css
script.js
```
